# 项目启动指南

> 从零在新电脑上启动 smart-travel/multi-agents 项目的完整步骤。

---

## 前置条件

| 工具 | 最低版本 | 用途 |
|------|---------|------|
| Python | 3.12+ | 运行时 |
| Git | 任意 | 拉取代码 |
| Docker Desktop | 4.x | 运行 PostgreSQL + Redis |

---

## 第一步：克隆代码

```bash
git clone <你的仓库地址>
cd smart-travel/multi-agents
```

---

## 第二步：创建 Python 虚拟环境

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

---

## 第三步：安装依赖

```bash
pip install -r requirements.txt
```

如果安装 `hiredis` 编译失败（Windows 常见），可以先跳过：
```bash
pip install redis>=5.0.0  # 不带 hiredis 也能用，只是性能稍慢
```

---

## 第四步：配置环境变量

在 `multi-agents/` 目录下创建 `.env` 文件：

```env
# LLM API Keys（必填）
DEEPSEEK_API_KEY=你的DeepSeek密钥
DASHSCOPE_API_KEY=你的DashScope密钥

# 可选：LangSmith 追踪
LANGCHAIN_TRACING_V2=false
LANGCHAIN_API_KEY=

# 数据库（默认值即可，与 docker-compose.yml 一致）
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/smart_travel
REDIS_URL=redis://localhost:6379/0
```

**API Key 获取方式：**
- DashScope（通义千问）：https://dashscope.console.aliyun.com/
- DeepSeek：https://platform.deepseek.com/

---

## 第五步：启动 Docker 基础设施

确保 Docker Desktop 已启动，然后：

```bash
docker compose up -d
```

这会启动两个容器：
- `smart-travel-pg` — PostgreSQL 15（端口 5432）
- `smart-travel-redis` — Redis 7（端口 6379）

验证容器状态：
```bash
docker ps
```

应该看到两个容器都是 `Up` 状态。

> **首次启动说明：** 数据库表会在应用首次连接时自动创建（通过 `db/postgres.py` 的迁移机制），无需手动建表。

**数据迁移（可选）：** 如果之前使用过 SQLite 版本（`data/chat_history.db`），需要把历史会话迁移到 PostgreSQL：

```bash
cd multi-agents
python scripts/migrate_sqlite_to_pg.py
```

---

## 第六步：运行项目

### 方式 A：Streamlit UI（推荐）

```bash
cd multi-agents
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。

### 方式 B：FastAPI 后端

```bash
cd multi-agents
uvicorn server:app --reload --port 8000
```

API 地址：`http://localhost:8000`

---

## 第七步：验证一切正常

### 运行测试

```bash
cd multi-agents

# 运行不依赖外部服务的测试（推荐先跑这个）
.venv/Scripts/python -m pytest tests/test_memory_working.py tests/test_memory_long_term.py tests/test_memory_router.py tests/test_memory_promotion.py tests/test_memory_integration.py -v

# 运行需要 Redis 的测试
.venv/Scripts/python -m pytest tests/test_memory_short_term.py -v

# 运行需要 PostgreSQL 的测试
.venv/Scripts/python -m pytest tests/test_db_postgres.py tests/test_db_models.py tests/test_db_integration.py -v

# 全部一起跑
.venv/Scripts/python -m pytest tests/ -v
```

## 常见问题

### Q: Docker 容器启动后端口被占用？

```bash
# 查看占用端口的进程
netstat -ano | findstr :5432
# 或者修改 docker-compose.yml 中的端口映射
```

### Q: Redis 连接失败但项目还能用吗？

可以。短期记忆会自动降级到进程内存 dict，不影响功能，只是重启后缓存丢失。

### Q: PostgreSQL 连接失败怎么办？

检查：
1. Docker 容器是否在运行：`docker ps`
2. `.env` 中的 `DATABASE_URL` 是否正确
3. 端口 5432 是否被其他 PostgreSQL 占用

### Q: 没有 RAG 知识库数据怎么办？

项目可以正常运行，只是 RAG 检索返回"知识库未初始化"。如需构建知识库：
```python
from tools.rag_tool import get_rag_instance
rag = get_rag_instance()
rag.build_knowledge_base("path/to/your/travel/docs", file_type="directory")
```

### Q: 如何查看 PostgreSQL 中的数据？

推荐工具：
- **pgAdmin 4**（免费）：https://www.pgadmin.org/download/
- **DBeaver**（免费）：https://dbeaver.io/
- **Navicat**（付费）

连接信息：
```
Host: localhost
Port: 5432
Database: smart_travel
Username: postgres
Password: postgres
```

### Q: 如何查看 Redis 中的数据？

```bash
# 进入 Redis 容器
docker exec -it smart-travel-redis redis-cli

# 查看所有 key
KEYS *

# 查看某个 session 的短期记忆
LRANGE smart_travel:short_term:<session_id> 0 -1
```

或使用 GUI 工具：**Another Redis Desktop Manager**（免费）

## 换电脑快速恢复清单

1. `git clone` 拉代码
2. 创建 `.venv` + `pip install -r requirements.txt`
3. 创建 `.env`（从旧电脑复制或重新填写 API Key）
4. 安装并启动 Docker Desktop
5. `docker compose up -d`
6. `streamlit run app.py`

总共约 5-10 分钟即可恢复开发环境。
