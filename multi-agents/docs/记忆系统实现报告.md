## 5. 各模块接口

### WorkingMemory（进程内，同步）
```python
wm = WorkingMemory(max_entries_per_session=50)
wm.update(session_id, {"key": "value"})
wm.get_context(session_id) → dict
wm.get_history(session_id, last_n=10) → list[dict]
wm.export_for_persistence(session_id) → dict
wm.clear(session_id)
```

### ShortTermMemory（Redis，异步）
```python
stm = ShortTermMemory(max_turns=20, ttl_seconds=1800)
await stm.add_message(session_id, role, content)
await stm.get_history(session_id, last_n=None) → list[dict]
await stm.get_context_window(session_id, max_tokens=4000) → str
await stm.clear(session_id)
```

### LongTermMemory（PG + Chroma，异步）
```python
ltm = LongTermMemory()
await ltm.get_preferences(user_id) → dict
await ltm.update_preferences(user_id, **fields)
await ltm.get_travel_history(user_id, limit=5) → list[dict]
await ltm.get_summaries(user_id, limit=5) → list[dict]
await ltm.search_knowledge(query, k=3) → str
await ltm.get_user_profile(user_id) → dict
```

### MemoryRouter（意图路由，异步）
```python
router = MemoryRouter(working, short_term, long_term)
context = await router.load_context(session_id, user_id, user_query) → dict
# 返回: {working, short_term?, preferences?, travel_history?, knowledge?}
```

### MemoryPromotion（写回，异步）
```python
promotion = MemoryPromotion(short_term, long_term, working)
result = await promotion.promote(session_id, user_id, user_message, assistant_response, pg_session_id?)
# 返回: {saved_to_pg, saved_to_short_term, preferences_updated, travel_history_saved}
```

### MemoryManager（全局单例）
```python
from memory import get_memory_manager
mgr = get_memory_manager()
mgr.working / mgr.short_term / mgr.long_term / mgr.router / mgr.promotion
```

## 7. 容错设计

| 场景 | 行为 |
|------|------|
| Redis 不可用 | 自动降级到内存 dict，不抛异常 |
| PostgreSQL 不可用 | 跳过 PG 相关写入，workflow 正常运行 |
| Chroma 未初始化 | 返回 "知识库未初始化"，不 crash |
| 记忆加载失败 | catch + 打印警告，返回空 context |
| 记忆写回失败 | catch + 打印警告，不影响 final_answer 输出 |

## 8. 请求生命周期

```
用户发消息: "帮我规划去杭州3天，预算3000"
│
├─ main_agent_node 入口:
│   ├── MemoryRouter.load_context()
│   │   ├── 工作记忆: {} (新请求)
│   │   ├── 短期记忆: [上一轮对话] (Redis)
│   │   └── 长期记忆: 偏好 + 旅行历史 (PG)
│   └── WorkingMemory.update({last_query, agent})
│
├─ LangGraph workflow 执行 (Planner → Executor → Summarizer)
│
└─ final_output_node 出口:
    └── MemoryPromotion.promote()
        ├── → Redis (短期缓存)
        ├── → 提取偏好 "预算3000" → PG user_preferences (budget_level="舒适型")
        ├── → 检测行程规划 → PG travel_history (destination="杭州")
        └── WorkingMemory.clear()
```
