# 反馈与用户画像解耦 — 实施计划（v2，已采纳审核意见）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将"用户画像更新"从 main agent 的流程分类中完全解耦。画像写入统一收敛到记忆写回层（promote + LLM 提取 → PG `user_preferences`），读取统一收敛到 `state.memory_context`，main agent 只负责 travel/conversation 流程路由，删除 feedback 节点与 JSON 画像。

**Architecture:**

```
                    写入（每轮对话结束，与分类无关）          读取（请求入口，注入全局 state）
用户消息 → main 二分类 → 流程执行 → final_output → promote(LLM 提取) → PG user_preferences
                                                                        ↑
                                                    router.load_context → state.memory_context
                                                                        ↓
                                              各 agent 从 state 读（不再各自读 JSON）
```

**Tech Stack:** LangGraph, Qwen3 (LLM 提取), PostgreSQL (user_preferences), 现有 memory/promotion.py

## Global Constraints

- 画像存储唯一来源：PG `user_preferences`（JSON 画像 `user_profile_manager` 淘汰）
- 画像写入唯一入口：`MemoryPromotion.promote()`（每轮对话结束触发，**带超时，不阻塞流式**）
- 画像读取唯一入口：`MemoryRouter.load_context()` → `state.memory_context`（**偏好默认总是加载**，不做关键词判断）
- main agent 只做流程路由（travel/conversation 二分类），不处理反馈语义
- LLM 提取失败/超时 → 回退现有正则（保证可用性）
- **聊天消息持久化职责明确**：由 `chat_service` 统一保存（promote 不再保存消息，避免重复）
- **数组字段合并语义**：append + 去重（画像累积，不覆盖）

- [ ] **Step 1: 写 Pydantic 提取模型（含 import json）**（审核意见 2）

```python
"""偏好提取器 — LLM 驱动（Pydantic 结构化输出）"""
import json  # ⚠️ 审核意见：必须导入
from typing import List, Optional
from pydantic import BaseModel, Field
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from config.settings import QWEN3_MODEL, QWEN3_API_BASE, DASHSCOPE_API_KEY


class PreferenceExtraction(BaseModel):
    """LLM 提取的偏好更新（字段名与 ALLOWED_PREF_FIELDS 一致）"""
    travel_style: List[str] = Field(default_factory=list)
    budget_level: Optional[str] = None
    hotel_preference: List[str] = Field(default_factory=list)
    liked_activities: List[str] = Field(default_factory=list)
    disliked_activities: List[str] = Field(default_factory=list)
    cuisine_preference: List[str] = Field(default_factory=list)
    transport_priority: List[str] = Field(default_factory=list)
    dietary_restrictions: List[str] = Field(default_factory=list)
    destination_types: List[str] = Field(default_factory=list)
    travel_season_preference: List[str] = Field(default_factory=list)
    daily_schedule_preference: Optional[str] = None
    max_daily_budget: Optional[float] = None
    has_preference: bool = Field(default=False)
    confidence: float = Field(default=0.0, ge=0, le=1)


async def extract_preferences_with_llm(user_msg: str, assistant_msg: str, current_prefs: dict) -> dict:
    """LLM 提取偏好，返回字段与 ALLOWED_PREF_FIELDS 对齐的 dict；无偏好或低置信返回 {}"""
    llm = ChatOpenAI(model=QWEN3_MODEL, base_url=QWEN3_API_BASE,
                     api_key=DASHSCOPE_API_KEY, temperature=0.1)
    structured = llm.with_structured_output(PreferenceExtraction)
    prompt = ChatPromptTemplate.from_messages([
        ("system", """你是用户旅行偏好分析师。从用户消息中提取明确的偏好信息。

规则：
- 只提取用户明确表达的内容，不要臆测
- 隐含语义也要提取（"带着爸妈"→travel_style=["家庭游","慢节奏"]；"别太赶"→travel_style=["慢节奏"]）
- 无偏好信息时 has_preference=false
- confidence<0.6 时调用方应丢弃结果"""),
        ("human", "用户消息：{user_msg}\n\n助手回复：{assistant_msg}\n\n当前画像：{current_prefs}")
    ])
    chain = prompt | structured
    result = await chain.ainvoke({
        "user_msg": user_msg,
        "assistant_msg": assistant_msg,
        "current_prefs": json.dumps(current_prefs, ensure_ascii=False, default=str),
    })
    if not result.has_preference or result.confidence < 0.6:
        return {}
    return result.model_dump(exclude={"has_preference", "confidence"})
```

- [ ] **Step 2: promotion.py 接入（正则优先 + LLM 兜底 + 超时）**（审核意见 1）

```python
# 正则快路径
preferences = self._extract_preferences(user_message, assistant_response)

# 正则未命中 → LLM 兜底（带 5 秒超时，不阻塞流式输出）
if not preferences:
    try:
        current_prefs = await self.long_term.get_preferences(user_id) or {}
        preferences = await asyncio.wait_for(
            extract_preferences_with_llm(user_message, assistant_response, current_prefs),
            timeout=5.0,
        )
        if preferences:
            print(f"  [LLM] 提取到偏好: {preferences}")
    except asyncio.TimeoutError:
        print("  [WARN] LLM 偏好提取超时，跳过")
    except Exception as e:
        print(f"  [WARN] LLM 偏好提取失败: {e}")
```

> 注意：`final_output` 中 promote 仍在 await，但 LLM 分支有 5s 超时兜底；极端情况下可后续改后台任务。
